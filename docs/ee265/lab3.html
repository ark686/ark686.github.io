2.5 Discrete Time Sinusoidal Signals ​

The continuous time signal for of a sinusoid can be given by:

y(t)=A×sin⁡(2πfot+θ)

where

SymbolDescription
AAmplitude
foFrequency (in Hertz)
θPhase angle (in radians)

Often we use angular frequency ω (in radians/second), with:

ω=2πf

And the period (time for one cycle) T equal to:

T=1f=2πω

Let the sampling frequency (sampling the continuous time signal to create a discrete time signal) be Fs (samples per second). Then the sampling time interval Ts in seconds is:

Ts=1Fs

The discrete time sinusoidal signal can then be expressed as:

y[n]=A×sin⁡(2πfoTsn+θ)

It also makes sense to specify frequencies in terms of cycles per sample instead of cycles per second:

fd=fo (cycles/second)Fs (samples/second)=foFs (cycles/sample)

And since Ts=1Fs:

y[n]=A×sin⁡(2πfdn+θ)
  1. Add an appropriate section header, e.g., %% 2.5 Discrete Time Sinusoidal Signals.

3. Appendix A – MyStem MATLAB Function ​

matlab
function MyStem(sp1, sp2, sp3, x, y, titlex)
% sp1, sp2, sp3 subplot parameters
% x, y values to plot
% titlex - optional title

    % Define subplot
    subplot(sp1, sp2, sp3);

    % Stem 'x' versus 'y'
    stem(x, y, 'filled');

    % Set axis to maximum extend of values
    ymin = min(y);
    ymax = max(y);
    if (ymax - ymin) < 1
      ymax = ymin + 1;
    end
    axis([min(x) max(x) ymin ymax]);

    % Display titles
    if nargin > 5
        title(titlex, 'FontSize', 14);
    end

    % Turn on grid
    grid on;
end
