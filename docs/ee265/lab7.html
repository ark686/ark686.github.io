2. Convolution ​

Convolution is an extremely useful process in digital signal processing which can be used to determine the output of a system from a given input signal.

The mathematical process of convolution for a discrete time signal is given by the following equation:

(1)y[n]=∑k=0∞(x[k]×h[n−k])

where x[k] is the input signal to the system and h[n−k] is the impulse response of the system.

2.1 Convolution Example ​

Suppose that a system, known as a difference system, has h=[1, −1] (i.e., y[n]=x[n]−x[n−1]). Next suppose that the input signal to the system is x[n]=[1, 2, 3]. What is the output of the system when the input signal is passed through it?

Solution:

The solution to this question can be found by convolving both x[n] and h[n] together, either by hand or using MATLAB.

To better understand the process of a convolution, the steps needed to determine the output of the system using the convolution equation, given in (1), are done by hand below.

k:012
y[0]=x[0]×h[0−0]+ x[1]×h[0−1]+ x[2]×h[0−2]=1(1)+2(0)+3(0)=1
y[1]=x[0]×h[1−0]+ x[1]×h[1−1]+ x[2]×h[1−2]=1(−1)+2(1)+3(0)=1
y[2]=x[0]×h[2−0]+ x[1]×h[2−1]+ x[2]×h[2−2]=1(0)+2(−1)+3(1)=1
y[3]=x[0]×h[3−0]+ x[1]×h[3−1]+ x[2]×h[3−2]=1(0)+2(0)+3(−1)=−3
y[4]=x[0]×h[4−0]+ x[1]×h[4−1]+ x[2]×h[4−2]=1(0)+2(0)+3(0)=0

Table 1: Convolution Example

This can be verified using the MATLAB conv() function: conv([1 2 3], [1 -1]). The result returned is: [1 1 1 -3].

The overall effect of the convolution is to pass x[n] through the system h[n] one sample at a time. Below is a brief description of what the convolution actually does:

  • At time zero, the first sample of x[n], which is 1, enters the system and encounters a multiplication by h[0] which equals 1, the result is of course 1.
  • On the following sample, x[0] moves one more sample into the system and is multiplied by h[1] (−1). The next value of x[n], which is 2, enters the system and encounters a multiplication by h[0] (+1). These multiplication results are then added together and the result is 1 again.
  • This process repeats over again for each value of x[n] until all values of x[n] have been multiplied by all the elements of h[n].

3. Image Processing ​

Digital signal processing techniques such as convolution can be used to process video or images. In this section we will examine how digital signal processing can be used to process an image.

We can extend convolution to two dimensions. The general expression of convolution in two dimensions can be given by:

f(x,y)=∑i∑jg(x,y)⋅h(x−i, y−j)

Each pixel in the output image f(x,y) is given by the input image g(x,y) convolved with image h(x,y).

For the sake of simplicity, the image h is often:

  • Of odd size (3×3, 5×5, 7×7, ⋯)
  • Centred, i.e., the pixel with coordinates (0, 0) is at the centre of the image h

The image h is called by different names, depending on the context: filter, mask, kernel, window, pattern or point spread function (PSF).

For example:

Figure 2: 2D Convolution Example

Note that the filter h is flipped both in the horizontal and vertical directions before being "applied" to g (e.g., to calculate f2,2, g3,3 is multiplied by h−,−). But most often, h is symmetrical in the horizontal and vertical directions, so this "flipping" is not obvious it is happening.

Now there is an issue at the outside boundary of the images (e.g., how do you calculate f(1, 1) where you need g(0, 0), g(0, 1), g(2, 0) etc.?). You want the output image f(x,y) to be the same size as the input image g(x, y). A typical approach is to pad a ring of pixels around g(x, y) of either zeros or duplicating the outside pixels of g(x, y).

A number of different operations can be performed based on the value of the filter/kernel. For example for 3×3:

OperationFilter / Kernel
Identityh=[000010000]
Box Blurh=19[111111111]
Gaussian Blurh=116[121242121]
Sharpenh=[0−10−15−10−10]
Edge Detectionh=[0−10−14−10−10] or (Laplacian) h=[−1−1−1−18−1−1−1−1]
Edge Detection (Vertical)h=[10−120−210−1]
Edge Detection (Horizontal)h=[121000−1−2−1]

The image file format that we will use in this lab for convolution is an 8-bit grayscale image. This means that the file contains values for row pixels (vertically) by col pixels (horizontally) and each pixel contains an 8-bit value, ranging from 0 (black) to 255 (white).

3.3 Gaussian Blur (3 x 3) ​

Perform a 3 x 3 Gaussian Blur on a grayscale image:

  1. Create a new MATLAB function GaussianBlur3x3() (copy in the code shown in Figure 6).

    matlab
    function [image_out] = GaussianBlur3x3(image)
% Inputs:
%   image     = Input grayscale image
% Outputs:
%   image_out = Processed image

    % Define the filter
    h = [1/16 2/16 1/16; 2/16 4/16 2/16; 1/16 2/16 1/16];

    % Convert the grayscale image uint8 to double
    g = double(image);

    % Perform the convolution
    f = conv2(g, h);

    % f will have an extra ring of pixels (just the way MATLAB does conv2),
    % extract subimage by removing extra ring of pixels
    [rows, cols] = size(f);
    subimage = f(2:rows-1, 2:cols-1);

    % Convert subimage to uint8 (values 0 to 255)
    image_out = uint8(subimage);
end

    Figure 6: GaussianBlur3x3() MATLAB Function

  2. Use GaussianBlur3x3() on the grayscale image from section 3.2 and display.
