2. Moving Average Systems ​

A "moving average system" takes a number of input samples and determines a new value for each output sample based on a weighted sum of the input samples. Consider the following three moving average systems:

Moving Average SystemOrder
y(n)=12[x(n)+x(n−1)]First
y(n)=14[x(n)+x(n−1)+x(n−2)+x(n−3)]Third
y(n)=16[x(n)+x(n−1)+x(n−2)+x(n−3)+x(n−4)+x(n−5)]Fifth

The "order" relates to the number of additional terms. Note that the sum of the coefficients multiplied by the scaling factor equate to one, so that the output for a constant input will be the same value as the input. A moving average system can be thought of as "smoothing out" changes in the input signal. The higher the order of the system, the more spread out this smoothing becomes.

Following the class notes, we want to confirm the response of this system to three selected inputs:

  1. Impulse δ(n)
  2. Step u(n)
  3. Sinusoid cos⁡(ωn)

2.1 Moving Average Function ​

  1. An example MATLAB function that generates a first-order Moving Average output for a given input vector is shown in Figure 2.

    matlab
    function y = MA1(n, x)
% n, x: Input vector
% y   : Output vector

    y = zeros(1, length(n), 'double');
    for i = 1:length(n)
        if i > 1
            y(i) = 1/2 * (x(i) + x(i-1));
        else
            y(i) = 1/2 * x(i);
        end
    end
end

2.4 Frequency Responses ​

The frequency response of a Moving Average system (defined as the "Gain" (change to original amplitude) and "Phase" (phase angle shift relative to original signal)) varies with the frequency of the input signal.

Consider a first-order Moving Average system:

y(n)=12[x(n)+x(n−1)]

To determine the Frequency Response, we can use a Phasor Approach with x(n)=cos⁡(ωn):

Y=12[1+1×e−jω]y(n)=A×cos⁡(ωn+φ)

where

A=Amplitude of Yφ=Phase angle of Y

In MATLAB, this can be found by:

matlab
Y = 1/2 * (1 + exp(1i * -w));
A = abs(Y);
phi = angle(Y);
y = A * cos(w * t + phi);

3. Weighted Moving Average Systems ​

Consider the difference between a moving average and a weighted moving average of order two:

SystemEquation
Moving Average (second order)y(n)=13[x(n)+x(n−1)+x(n−2)]
Weighted Moving Average (second order)y(n)=14[x(n)+2×x(n−1)+x(n−2)]

The "order" relates to the number of additional terms. Note that the sum of the coefficients multiplied by the scaling factor equate to one, so that the output for a constant input will be the same value as the input. Note also that there are multiple possible values for the Weighted Moving Average coefficients.

We want to confirm the response of this system to three selected inputs:

  1. Impulse δ(n)
  2. Step u(n)
  3. Sinusoid cos⁡(ωn)

Appendix A – Moving Average System Impulse Responses MATLAB Code ​

matlab
%% 2.2 Impulse Responses
%===================================================================
% Define input impulse signal x(n)
n = -4:8;
x = double(n == 0); % Cast to double or may cause calculation issues later

% Generate Moving Average Signals
ma1 = MA(1, n, x);
ma3 = MA(3, n, x);
ma5 = MA(5, n, x);

% Display results
figure('Name', '2.2 Impulse Responses');
MyStem(4, 1, 1, n, x, 'Input x(n) = \delta(n)');
MyStem(4, 1, 2, n, ma1, '1st Order Moving Average');
MyStem(4, 1, 3, n, ma3, '3rd Order Moving Average');
MyStem(4, 1, 4, n, ma5, '5th Order Moving Average');

function MyStem(sp1, sp2, sp3, x, y, titlex)
% sp1, sp2, sp3 subplot parameters
% x, y values to plot
% titlex - text for title

    % Define subplot
    subplot(sp1, sp2, sp3);

    % Stem 'x' versus 'y'
    stem(x, y, 'filled');

    % Display title
    title(titlex);

    % Adjust y axis
    miny = min(y);
    maxy = max(y);
    axis([min(x) max(x) miny maxy]);

    % Adjust y ticks
    if miny < 0 && maxy > 0
        yticks([miny 0 maxy]);
    else
        yticks([miny (miny + (maxy - miny)/2) maxy]);
    end

    % Turn on grid
    grid on;
end

xt = cos(w * t);
n = 0:16;
xn = cos(w * n);

ma5 = MA(5, n, xn);

% Display results
titlex = sprintf('2.4 Frequency Response, cos(%s)', 'pi/4 * n');

stem(n, ma1, 'color', [1 0 0], 'linestyle', 'none');

% Adjust axis

% Title
