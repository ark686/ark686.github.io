3.4 Plotting ​

MATLAB has facilities for plotting. For example, to plot y=x2 for 0≤x≤100:

matlab
>> figure(1);
>> x = 0:100;
>> y = x.^2;
>> plot(x, y);
>> grid on;
>> title("Example Plot");
>> xlabel("x");
>> ylabel("y = x^2");

Note the syntax for "y = x.^2". The "." operator is required to indicate that this is an element-by-element operation, as x is a vector.

3.5 MATLAB Files ​

MATLAB files typically have a ".m" extension. Two types of files of interest:

  1. Script files
  2. Function files

3.5.1 Script Files ​

Rather than having to enter commands manually in the Command Window, commands can be included in a MATLAB script file and then executed in the Command Window by specifying the name of the file (without the ".m" extension). The script file can be thought of as a MATLAB "program".

Comments are useful to explain what a MATLAB script is doing. Comments in MATLAB begin with a "%", the remainder of the line is ignored (so can be used on a line by itself or at the end of a line).

The "%%" is used to denote the start of a "section" and are useful when we "publish" a MATLAB script (which we will see later).

An example of a MATLAB script (start of EE265 Lab 2) is shown below, the resulting figure is shown in Figure 2.

matlab
%% EE265 Lab 2 - Continuous Signals
%===================================================================
% Andrew Kostiuk

clear;      % Clear all variables
close all;  % Close all figures

%% STEP Functions
%===================================================================
% Create a time vector containing -2 to 6 seconds in steps of 0.01 seconds
t = -2:0.01:6;

% Create step functions
u0 = t >= 0;    % u(t)
u1 = t >= 3;    % u(t - 3)
u2 = t >= -1;   % u(t + 1)
u3 = u2 - u1;   % u(t + 1) - u(t - 3)

% Open a new figure for plotting
figure('Name', 'Step Functions');

% Plot each step function as a subplot
Mysubplot(4, 1, 1, t, u0, 'u(t)');
Mysubplot(4, 1, 2, t, u1, 'u(t - 3)');
Mysubplot(4, 1, 3, t, u2, 'u(t + 1)');
Mysubplot(4, 1, 4, t, u3, 'u(t + 1) - u(t - 3)');

Figure 2: Example Script Output

3.5.2 Function Files ​

MATLAB user-defined functions are useful for performing the same operations multiple times in a MATLAB script as well as segmenting the code into more manageable size pieces.

Each MATLAB function must be its own file, with the name of the file being "<function name>.m".

An example of a MATLAB function is shown below ("Mysubplot.m" used in the script in the previous section).

matlab
function Mysubplot(sp1, sp2, sp3, x, y, titlex)
% sp1, sp2, sp3 subplot parameters
% x, y values to plot
% titlex text for title

% Define subplot
subplot(sp1, sp2, sp3);

% Plot 'x' versus 'y'
plot(x, y);

% Calculate 'y' margin (25%)
ymargin = (max(y) - min(y)) * 0.25;

% Set margins (full extent of 'x', 25% above and below 'y')
axis([min(x) max(x) (min(y) - ymargin) (max(y) + ymargin)]);

% Display title
title(titlex);

% Turn on grid
grid on;
end

Note that the Mysubplot() function only performs actions, it does not return any values. Functions can be defined to return one value:

matlab
function maxValue = ReturnMax(v)
% v = Input vector
% maxValue = Maximum value in vector
maxValue = max(v);
end

This can be used in a script as:

matlab
>> ReturnMax([1 2 3 4 5 2.5])
ans = 5

Functions can be defined to return multiple values (two in this example):

matlab
function [minValue maxValue] = ReturnMinMax(v)
% v = Input vector
% minValue = Minimum value in vector
% maxValue = Maximum value in vector
minValue = min(v);
maxValue = max(v);
end

This can be used in a script as:

matlab
>> [a b] = ReturnMinMax([1 2 3 4 5 2.5])
a = 1
b = 5

6. Appendix – MeanAndPower() MATLAB Function ​

File "MeanAndPower.m", demonstrates:

  • Returning multiple values
  • Using "for" loop
  • Using conditional "if" statement
matlab
function [mean, power] = MeanAndPower(t, f, t1, t2)
% Inputs:
%   t = Vector of time values
%   f = Vector of function values
%   t1 = Start time of a cycle
%   t2 = End time of the same cycle
% Outputs:
%   mean = Mean value
%   power = Power value

% Initialize accumulators
accumulator1 = 0;
accumulator2 = 0;

% Determine delta t (time between samples)
dt = t(2) - t(1);

% Iterate through samples
for i = 1:length(t)
    % Check if sample is in time window
    if t(i) >= t1 && t(i) < t2
        % Add to accumulators
        accumulator1 = accumulator1 + (f(i) * dt);
        accumulator2 = accumulator2 + (f(i)^2 * dt);
    end
end

% Average over cycle
mean = accumulator1 / (t2 - t1);
power = accumulator2 / (t2 - t1);
end
