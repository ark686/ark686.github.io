1. Introduction ​

This lab looks at Infinite Impulse Response (IIR) systems and Pole-Zero plots.

2. IIR System Transfer Function ​

Consider the first order Infinite Impulse Response (IIR) system given by the input-output relationship:

(1)y(n)=c⋅y(n−1)+x(n)

where c is a constant.

Show that the transfer function of this system is:

(2)T(z)=11−c⋅z−1

3. IIR System MATLAB Function ​

In MATLAB, create a function for the IIR system (IIR.m) with the following content. Make sure to replace the "<Fill in code>" with the appropriate MATLAB code (and include it in-line in your lab report):

matlab
function [y] = IIR(c, N, x)
% Perform IIR y(n) = c*y(n-1) + x(n)
% Assume x(n<0)=0 and y(n<0)=0
% Inputs:
%   c = Constant
%   N = Vector of sample number
%   x = Vector of corresponding sample values
% Outputs:
%   y = Output vector

    y = zeros(1, length(N));
    for index = 1:length(N)
        if N(index) > 0
            y(index) = <Fill in code>;
        elseif N(index) == 0
            y(index) = <Fill in code>;
        end
    end
end

Using the transfer function, determine an expression for the impulse response (i.e., x(n)=δ(n)) for the first order IIR system, as a function of constant c (assume y(−1)=0). Include in your lab report.

6. Pole-Zero Plots ​

  1. Display Pole-Zero plots for the IIR system with c=0.9, −0.9, 1.1 and 1 (i.e., four separate Pole-Zero plots). To display a Pole-Zero plot:

    matlab
    figure;
zplane([z], [p]);
title('Pole-Zero Plot for ...');

    where "[z]" is a column (vertical) vector of zeros and "[p]" is a column (vertical) vector of poles. An example for c=0.9 is shown in Figure 2.

    Figure 2: Example Pole-Zero Plot for c = 0.9

  2. In your lab report, describe how the stability of the system for each c can be determined from the Pole-Zero plots and how that corresponds to the determination of stability in section 4.

7. Apply IIR System to DJI Data ​

  1. Right-click on DJI.csv and "Save link as..." to "DJI.csv" in your working directory. The file contains the daily closing value of the Dow Jones Industrial financial index. To read in the daily closing value, use the following code:

    matlab
    M = csvread('DJI.csv', 1, 1);
x = M(:, 4)';

  2. Use the Moving Average function from a previous lab to generate the 21-day Moving Average of the DJI data.

  3. Use an IIR system with input-output relationship y(n)=0.95×y(n−1)+0.05×x(n) on the DJI data. Note that IIR.m has no gain on the input, so pass in 0.05*x as the input.

  4. Plot the original data, the Moving Average output and the new IIR output on the same plot. Include a legend, labels, grid, etc. Your results should look similar to Figure 3.

    Figure 3: Example DJI Closing Value Plot

  5. Note that the IIR plot takes a long time to get up to the daily data. Create a new MATLAB function, IIR2.m, with the following parameters and modify the function accordingly:

    matlab
    function [y] = IIR2(c, N, x, yInitial)
% Perform IIR y(n) = c*y(n-1) + x(n)
% Assume x(n<0)=0 and y(-1)=yInitial
% Inputs:
%   c        = Constant
%   N        = Vector of sample number
%   x        = Vector of corresponding sample values
%   yInitial = Value to use for y(-1)
% Outputs:
%   y        = Output vector

  6. Now plot the original data, the Moving Average output and the new IIR2 output (passing in a suitable value of yInitial to fix the Figure 3 problem) on the same plot. Include a legend, labels, grid, etc.

  7. Display another plot zoomed in on the data for Trading Days 100 to 150.

  8. In your lab report, discuss the differences between using the Moving Average and IIR2, and contrast the number of terms in the system between the two.
