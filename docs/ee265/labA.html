2. The Fourier Series ​

In previous labs, we spent a fair amount of time examining sinusoidal signals which have been mentioned as very important in digital signal processing applications. You may however be wondering what can be done if a non-sinusoidal signal is encountered if all we know how to do is process sinusoidal signals. This brings us to an important mathematical series called the Fourier Series.

Simply put, the Fourier Series allows a periodic function/signal to be represented by a number of cosine and sine functions that are summed together as given by the following equation:

(1)f(t)=∑k=−∞∞akej(kω0t)

where ak are coefficients determined by analysis of the signal being reproduced and ω0 is the fundamental frequency of the signal in radians/s.

The coefficients ak can be determined using the following equation:

(2)ak=1T0∫0T0x(t)e−j(kωot)dt

where x(t) is the signal being evaluated and T0 is the period of the signal (note that T0=2πω0).

It is useful to note that when k=0 in the above equation, a0 becomes the average (DC) value of x(t).

3. Even Square Waves ​

In this section, we will examine the Fourier Series Coefficients for a number of periodic even square wave signals (shown in Figure 1). A signal is referred to as "even" as it is symmetrical around the time axis. Once the coefficients for the Fourier Series have been found, we can reconstruct the signals using the Fourier Coefficients and plot the results in MATLAB to verify that the Fourier Series works.

Square waves can differ through a number of parameters:

  • Amplitude: Half of the difference between the maximum and minimum of a signal. For example, square wave (a) has an amplitude of 1/2.
  • DC Offset: Constant amount added to the signal. For example, square wave (a) has a DC offset of 1/2.
  • Frequency: The number of cycles per second (in Hz).
  • Duty Cycle: The portion (as a percentage) of the signal that is "high" versus "low". Duty cycles are listed on each signal.
  • Phase: Cycles are usually considered to be synchronized at t=0, with the beginning of the high portion. To get an even signal, the signal needs to be shifted to the left. For example, square wave (a) has a phase of +90∘.

5. Time Shift in Fourier Series ​

This section deals with the implementation of a phase shift (or time shift) when calculating a Fourier Series. A phase shift in the Fourier Series can be implemented with complex multiplication.

Once you have determined the Fourier Series coefficients, a time shift can be implemented by multiplying the coefficients by the following complex equation:

(16)akshift=ak e−jkω0τ

In equation (16), ω0 is the fundamental frequency of the waveform being produced and τ is the time shift amount.

Appendix A – SquareWave.m ​

matlab
function [tv, signal] = SquareWave(A, f0, duty, phase, DC, ...
    samplesPerCycle, cycles)
% SquareWave Generate a square wave with the given parameters
% Inputs:
%   A       = amplitude
%   f0      = Frequency of waveform (Hz)
%   duty    = duty cycle (0 to 1)
%   phase   = -180 to +180 degrees
%   DC      = dc offset
%   samplesPerCycle = samples per cycle
%   cycles  = number of cycles (must be integer > 0)
% Outputs:
%   tv      = time vector
%   signal  = signal vector

% Total number of samples
N = samplesPerCycle * cycles;

% Create a time vector
% Period
T = 1 / f0;
tv = 0:1:N-1;
tv = tv .* (1 / samplesPerCycle * T);

% Calculate the number of samples with amplitude +A
% Make sure it's an integer number
N_high = round(samplesPerCycle * duty);

% Calculate the number of samples with amplitude -A
N_low = samplesPerCycle - N_high;

% Create a single cycle of the signal
wave_cycle = [(A * ones(1, N_high)) (-A * ones(1, N_low))];

% Rotate cycle based on phase
if phase < 0
    phase = phase + 360;
end
shifted_wave = circshift(wave_cycle, ...
    samplesPerCycle - round(phase / 360 * samplesPerCycle));

% Make signal using required copies of shifted_wave
signal = repmat(shifted_wave, 1, cycles);

% Add the DC offset to the waveform
signal = signal + DC;

Appendix C – FourierSeries.m ​

matlab
function [a0, ak, akneg] = FourierSeries(kmax, y, f, Ns)
% FourierSeries Determine the Fourier Series Coefficients
% Inputs:
%   kmax  = Number of coefficients
%   y     = Signal
%   f     = Frequency (Hz)
%   Ns    = Number of samples per cycle
% Outputs:
%   a0    = a0 coefficient
%   ak    = Coefficients k = 1, 2, ..., kmax
%   akneg = Coefficients k = -1, -2, ..., -kmax

T = 1 / f;  % Period
w0 = 2 * pi * f;

a0 = sum(y(1:Ns)) / Ns;

for k = 1:kmax
    ak(k) = 0;
    for index = 1:Ns
        ak(k) = ak(k) + y(index) * ...
            exp(1i * -k * w0 * ((index-1) / Ns * T)) * (1 / Ns * T);
    end
    ak(k) = ak(k) / T;
    if abs(ak(k)) < 1e-10
        ak(k) = 0;
    end

    akneg(k) = 0;
    for index = 1:Ns
        akneg(k) = akneg(k) + y(index) * ...
            exp(1i * k * w0 * ((index-1) / Ns * T)) * (1 / Ns * T);
    end
    akneg(k) = akneg(k) / T;
    if abs(akneg(k)) < 1e-10
        akneg(k) = 0;
    end
end
