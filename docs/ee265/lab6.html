1. Introduction ​

This lab investigates Linear Time-Invariant (LTI) Systems.

Answer the following questions in your lab report:

  1. What defines a "linear" system?
  2. What defines a "time-invariant" system?
  3. Why are LTI systems useful?
  4. When is a LTI system not useful?

2.1 Pulse Generation Function ​

  1. Create a new MATLAB function file pulse.m which returns a vector of samples representing a single pulse with sloped edges.
  2. Add the template code shown in Figure 1 to the file and insert the required code. For example, pulse(-5:40, 5, 0, 5, 15, 25) would look like Figure 2.
matlab
function x = pulse(N, MAX, N1L, N1H, N2H, N2L)
% PULSE Generate samples for a single pulse with sloped edges
% N   = Vector of sample numbers
% MAX = Maximum value of pulse
% N1L = Sample number before start of rising edge
% N1H = Sample number where rising edge has reached a value of MAX
% N2H = Sample number before start of falling edge
% N2L = Sample number where falling edge has returned to zero

    % Generate signal vector of length N
    for index = 1:length(N)
        if N(index) <= N1L
            % Zeros before rising edge
            x(index) = <Insert code>;
        elseif N(index) <= N1H
            % Rising edge
            x(index) = <Insert code>;
        elseif N(index) <= N2H
            % Top of pulse
            x(index) = <Insert code>;
        elseif N(index) <= N2L
            % Falling edge
            x(index) = <Insert code>;
        else
            % Zeros for rest of signal
            x(index) = <Insert code>;
        end
    end
end

5. Determine Linearity and Time-Invariance ​

  1. y(n)=x(n)2
  2. y(n)=x(n2)
  3. y(n)=2x(n)+1
  4. y(n)=x(n)×x(n−1)
