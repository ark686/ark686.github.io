2.2 Filters ​

From [2], a filter is a device or process that removes some unwanted components or features from a signal. The frequency response of a filter can be classified by which frequency bands the filter passes (the passband) and which it rejects (the stopband).

Different types of filters include (see Figure 1):

  1. Low-pass: Low frequencies are passed, high frequencies are attenuated.
  2. High-pass: High frequencies are passed, low frequencies are attenuated.
  3. Band-pass: Only frequencies in a frequency band are passed.
  4. Band-stop: Only frequencies in a frequency band are attenuated.

Figure 1: Types of Filters

The "cutoff frequency" is the frequency beyond which the filter will attenuate signals. It is usually measured at a specific attenuation, typically −3 dB. The reason −3 dB is chosen is that it represents the "half-power" point, the frequency at which the output signal has half the power of the input signal.

Note that since power∝magnitude2, the output signal will be 0.5≈0.707 the magnitude of the input signal at the −3 dB point.

2.3 Determining Filter Frequency Response ​

The poles of a system determine the stability of a system (e.g., if all of the poles are within the Z-transform unit circle, the system will be stable). The poles and zeros of a system determine if a system is a filter, and if so, what type of filter. By understanding how poles and zeros define filters, we can use them to determine their frequency response.

The frequency response of a filter has two components:

  1. Magnitude Response: How the amplitude of the output signal is affected at different frequencies.
  2. Phase Response: How the phase of the output signal is affected at different frequencies.

Consider a system with two poles and two zeros shown in Figure 2:

Figure 2: System with Two Poles and Two Zeros

The frequency response is given by:

T(z)=bo(1−z1z−1)(1−z2z−1)(1−p1z−1)(1−p2z−1)T(z)=bo(z−z1)(z−z2)(z−p1)(z−p2)T(ejω)=bo(ejω−z1)(ejω−z2)(ejω−p1)(ejω−p2)T(ejω)=boU1∠θ1×U2∠θ2V1∠φ1×V2∠φ2

The magnitude of the frequency response of the system is given by:

|T(ejω)|=boU1×U2V1×V2

The phase response is given by:

∠T(ejω)=(θ1+θ2)−(φ1+φ2)

In other words:

  • At any particular angular frequency ω, the magnitude of the frequency response is given by the product of the lengths of the vectors from the zeros to ω divided by the product of the lengths of the vectors from the poles to ω.
  • At any particular angular frequency ω, the phase response is given by the sum of the angles of the vectors from the zeros to ω minus the sum of the angles of the vectors from the poles to ω.

Note:

  • ω=π corresponds to a frequency of Fs2 where Fs is the sampling frequency (see Figure 3).
  • The complete frequency response is obtained by evaluating T(ejω) for −π≤ω≤π (from 0≤ω≤π if a symmetrical frequency response).
  • As the point P moves closer to a zero, the length of the vector U decreases and so the magnitude response decreases.
  • As the point P moves closer to a pole, the length of the vector V decreases and so the magnitude response increases.
  • At a zero on the unit circle, the magnitude response falls to zero.
  • At a pole on the unit circle, the (theoretical) magnitude response goes to ∞ (do not attempt to put a pole on the unit circle!)

Figure 3: Angular Frequency and Sampling Frequency

3. Filters ​

3.1 Lowpass Filter (Simple) ​

Consider placing a zero at "-1" and a pole at "0" as shown in Figure 4. We will see how this will function as a lowpass filter ("simple" as it only has a single zero and a single pole).

Figure 4: Pole-Zero Plot for Lowpass Filter (Simple)

  1. Frequency Response at ω=0:

    The magnitude of the Frequency Response at ω=0 is given by:

    |T(ej0)|=Length of vector from zero to unit circle ω=0Length of vector from pole to unit circle ω=0=21=2|T(ej0)|=20×log10⁡(2)=6 dB

    The Phase Response at ω=0 is given by:

    ∠T(ej0)=(Angle of vector from zero to unit circle ω=0)−(Angle of vector from pole to unit circle ω=0)∠T(ej0)=(0∘)−(0∘)=0∘

  2. Frequency Response at ω=π:

    The magnitude of the Frequency Response at ω=π is given by:

    |T(ejπ)|=01=0    (−Infinity dB)

    The Phase Response at ω=π is given by:

    ∠T(ejπ)=(90∘)−(180∘)=−90∘

    The "90∘" above for the vector from the zero is not obvious as the zero is right at ω=π. In this case, consider if the frequency was just a "tiny" bit less than π. The unit circle is effectively vertical at ω=π and so the angle would be 90∘.

  3. Frequency Response at ω=π2:

    The magnitude of the Frequency Response at ω=π2 is given by:

    |T(ejπ/2)|=21=2    (20×log10⁡(2)=3 dB)

    The Phase Response at ω=π2 is given by:

    ∠T(ejπ/2)=(45∘)−(90∘)=−45∘

  4. Create a new section in your MATLAB script file, "%% 3.1 Lowpass Filter (Simple)".

  5. Display the Pole-Zero plot in MATLAB using:

    matlab

p = [0];
[b, a] = zp2tf(z, p, 1/2);

MyZplane(b, a, '3.1 Lowpass Filter (Simple)');

    The MATLAB function "zp2tf()" will convert the zeros and poles of a transfer function to the "b" and "a" coefficients of the transfer function:

    T(z)=b0+b1z−1+b2z−2+⋯+bMz−Ma0+a1z−1+a2z−2+⋯+aNz−N

    These coefficients are then used as parameters to MATLAB's "zplane()" function. In this case, we are calling "MyZplane()" which can be found in Appendix A, which does some formatting before calling "zplane()", as well as prints out the poles and zeros:

    text

  POLES:

    Note the third parameter in the call to "zp2tf()" of "1/2". This is a scaling factor as we want the gain of the filter to be 0 dB (i.e., 1) in the "passband". If you look at step 1, we see that the magnitude response is "2" at ω=0, so we need to compensate by scaling by "1/2".

3.2 Lowpass Filter ​

The "Lowpass Filter (Simple)" did not do a great job of getting rid of the higher frequencies. By looking at the output of the MyFreqz() function, we can see that the magnitude response at 0.9π was around −16 dB, meaning that the signal was not reduced by even 1/10th.

We can make it "better" (reduce the higher frequencies more) by using more poles and zeros. Fortunately there are a number of functions in MATLAB which will help us determine these poles and zeros rather than just trial-and-error.

  1. Create a new section in your MATLAB script file, "%% 3.2 Lowpass Filter".

  2. Generate the poles and zeros using the MATLAB "butter" function, specifying four poles and four zeros with a bandwidth of 0.5π:

    matlab

    Note that we scale the transfer function coefficients using "k", resulting in 0 dB for the magnitude response.

The Magnitude and Phase Response should look similar to Figure 7. Note the much sharper "roll off" of this filter compared to the Simple Lowpass Filter.

3.9 Aliasing and Lowpass Filter ​

One important use of lowpass filters is to prevent "aliasing" when resampling a signal to a lower sampling frequency. The maximum frequency which can be replicated in a sampled signal is half the sampling frequency [3] (e.g., if the sampling frequency is 8 kHz, the maximum signal frequency is 4 kHz).

If a sampled signal is resampled at a lower sampling rate and there are signal frequencies greater than half of the new sampling frequency in the original signal, the resampled signal's lower frequencies will be "corrupted" by values from the higher frequencies. In this section, we will demonstrate this and how a lowpass filter should be applied before resampling to a lower sampling rate.

  1. Create a signal which combines a 250 Hz sine wave and a 3,000 Hz sine wave sampled at 8 kHz:

    matlab
    Fs = 8000;
n = 1:Fs*2;
signal = sqrt(2)*sin(250/Fs * 2 * pi * n) + ...
    sqrt(2)*sin(3000/Fs * 2 * pi * n);

  2. Create a new signal by resampling the original signal at half the original sampling frequency (can be created by only using every second sample of the original signal; note it will be half the length of the original signal).

  3. Create a sharper lowpass filter and display its pole-zero plot and frequency response:

    matlab
    [z, p, k] = butter(12, 0.5);
[b, a] = zp2tf(z, p, k);

MyZplane(b, a, '3.9 Lowpass Filter for Anti-Aliasing');
MyFreqz(b, a, '3.9 Lowpass Filter for Anti-Aliasing');

  4. Use this filter to filter the original signal:

    matlab
    signal_lp = Filter(b, a, signal);

  5. Now resample this filtered signal (i.e., take every second sample).

  6. Display the Power Spectrum Densities of the original signal, the resampled signal without using a lowpass filter, and the resampled signal done after using the lowpass filter. Should look similar to Figure 9.

  7. Listen to each of the three signals (can use "Play()", listed in Appendix E).

Appendix A – MyZplane.m ​

matlab
function [z, p] = MyZplane(b, a, xtitle)
% Generate the Pole-Zero Plot for the transfer function
% Inputs:
%   b       Numerator coefficients of transfer function
%   a       Denominator coefficients of transfer function
%   xtitle  Title for figure
% Outputs:
%   z       Vector of zeros
%   p       Vector of poles

    isOctave = exist('OCTAVE_VERSION', 'builtin') ~= 0;

    % Plot using MATLAB zplane() function
    figure;
    if isOctave
        zplane(b, a);
    else
        [hz, hp, ht] = zplane(b, a);

        % Change marker size and colour
        if length(hp) > 0
            for i=1:length(hp)
                set(hp(i), 'Color', 'r');
            end
        end
        if length(hz) > 0
            for i=1:length(hz)
                set(hz(i), 'Color', 'r');
            end
        end
    end
    title(xtitle);
    grid on;

    % Determine zeros and poles
    [z, p, k] = tf2zp(b, a);

    % Print out values of zeros and poles
    fprintf("MyZplane ('%s'):\n", xtitle);
    if length(z) > 0
        fprintf("  ZEROS:\n");
        for i = 1:length(z)
            r = real(z(i));
            im = imag(z(i));
            if r ~= 0 && im ~= 0
                fprintf("    %6.3f + j%6.3f\n", r, im);
            elseif r ~= 0
                fprintf("    %6.3f\n", r);
            elseif im ~= 0
                fprintf("    j%6.3f\n", im);
            else
                fprintf("    %6.3f\n", 0);
            end
        end
    end
    if length(p) > 0
        fprintf("  POLES:\n");
        for i = 1:length(p)
            r = real(p(i));
            im = imag(p(i));
            if r ~= 0 && im ~= 0
                fprintf("    %6.3f + j%.3f\n", r, im);
            elseif r ~= 0
                fprintf("    %.3f\n", r);
            elseif im ~= 0
                fprintf("    j%.3f\n", im);
            else
                fprintf("    %.3f\n", 0);
            end
        end
    end
end

Appendix B – MyFreqz.m ​

matlab
function [h, w] = MyFreqz(b, a, xtitle)
% Generate Frequency Response plot for the transfer function
% Inputs:
%   b       Numerator coefficients of transfer function
%   a       Denominator coefficients of transfer function
%   xtitle  Title for figure
% Outputs:
%   h       Vector of response at each frequency (magnitude@phase)
%   w       Vector of angular frequencies (0 to pi)

    % Use MATLAB freqz to generate the data
    [h, w] = freqz(b, a);
    figure;

    % Set bottom level to -100 dB
    dbh = 20 * log10(abs(h));
    idx = (dbh < -100);
    dbh(idx) = -100;

    % Top plot is magnitude response in dB
    subplot(2, 1, 1);
    plot(w/pi, dbh);
    grid on;
    ylabel('Magnitude (dB)');
    xlabel('Normalized Frequency (\times \pi rad/sample)');
    ylim([-100 20]);
    xticks([0:0.1:1]);
    title(xtitle);

    % Bottom plot is phase response in degrees
    subplot(2, 1, 2);
    plot(w/pi, angle(h)/pi*180);
    grid("on");
    ylabel('Phase (degrees)');
    xlabel('Normalized Frequency (\times \pi rad/sample)');
    xticks([0:0.1:1]);

    % Display magnitude/phase for normalized w = 0, 0.5, 1.0
    N = length(w);
    fprintf("MyFreqz ('%s'):\n", xtitle);
    fprintf("    %7s  %7s  %4s\n", " pi", "    dB", " deg");
    for i = 1:N/10:N+1
        if i > N
            i = N;
        end
        index = floor(i);
        mag = dbh(index);
        phase = angle(h(index))/pi*180;
        fprintf("    %7.2f  %7.2f  %4.0f\n", w(index)/pi, mag, phase);
    end
end

Appendix C – Filter.m ​

matlab
function filtered = Filter(b, a, signal)
% Apply filter to signal
% Inputs:
%   b           Numerator coefficients of transfer function
%   a           Denominator coefficients of transfer function
%   signal      Input signal
% Outputs:
%   filtered    Filtered output

    N = length(signal);
    filtered = zeros(1, N);
    terms = length(b);

    % Apply coefficients
    for index = 1:N
        if index > terms
            for i = 1:terms
                if i == 1
                    filtered(index) = filtered(index) +...
                        b(i)*signal(index-i+1);
                else
                    filtered(index) = filtered(index) +...
                        b(i)*signal(index-i+1) -...
                        a(i)*filtered(index-i+1);
                end
            end
        end
    end

    % Discard first 100
    filtered = filtered(100:length(filtered));
end

Appendix D – PSD.m ​

matlab
function PSD(x, fs, xtitle)
% Generate Power Spectrum Density plot for the signal
% Inputs:
%   x       Vector of signal values
%   fs      Sampling frequency (in Hz)
%   xtitle  Title for plot

    % Perform FFT (Fast Fourier Transform)
    x = x(1:fs);
    xdft = fft(x);

    % Extract half
    N = length(x);
    xdft = xdft(1 : floor(N / 2));

    % Calculate PDF
    psdx = abs(xdft/N) .^ 2;
    psdx(2 : end - 1) = 2 * psdx(2 : end - 1);
    psd = 10 * log10(psdx);

    % Frequency vector for plotting
    freq = ([0:numel(psd)-1]./(numel(psd)-1))*(fs/2);

    % Plot PSD
    plot(freq, psd);
    xmax = fs / 2;
    xlim([0 xmax]);
    xticks([0 : fs / 16 : xmax]);
    ymax = 20;
    ymin = -100;
    ylim([ymin ymax]);
    yticks([ymin : 20 : ymax]);
    grid on;
    xlabel("Frequency (Hz)");
    ylabel("Power (dB/Hz)");
    title(xtitle);
end

function Play(x, Fs)
% Play the given audio signal
% Inputs:
%     x    Audio signal to play
%     Fs   Sampling frequency

    % Play audio signal
    soundsc(x, Fs);

    % MATLAB starts playing the sound and continues execution
    % immediately, before the sound finishes.
    % Octave completely plays the sound before continuing
    %
    % Check which program is being used and add an appropriate delay
    % if it is MATLAB

    % Check for not Octave
    if exist('OCTAVE_VERSION', 'builtin') == 0
        % Pause for the appropriate amount of time (in seconds)
        pause(length(x) / Fs);
    end
end
