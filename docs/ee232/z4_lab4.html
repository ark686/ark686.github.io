4.8 Gated D Latch ​

To deal with the issues of invalid states for SR Latches, a Gated D Latch can be constructed as shown in Figure 6.

The “transition” table (which is similar to a truth table used for combinational logic) for a Gated D Latch is shown below:

EnableDQ(t+1)Q(t+1)―
0xQ(t)Q(t)―
1001
1110

Table 7: Gated D Latch Transition Table

The “x” in the transition table indicates “don’t care” (the value does not matter). The transition table indicates that when Enable=0, the value of the outputs at any future time are the same as the current time (i.e., output values are being “held”).

4.9 D Flip-Flop ​

The most common and useful sequential logic circuit is the “D Flip-Flop”. It differs from the previous latches in that it uses an “edge triggered clock” input, meaning that the output only changes on the edge of the “clock” input. They can be constructed to be either “positive-edge triggered” (changes on the rising edge) or “negative-edge triggered” (changes on the falling edge).

The circuit for a “master-slave positive-edge triggered D Flip-Flop” is shown in Figure 7. Note that this is just one way of constructing a positive-edge triggered D Flip-Flop.

The transition table for a positive-edge triggered D Flip-Flop is shown below:

ClockDQ(t+1)Q(t+1)―
xxQ(t)Q(t)―
↑001
↑110

Table 8: Master-Slave Positive-Edge Triggered D Flip-Flop Transition Table

Its operation can be thought of as: Input D is “sampled” on the rising edge of Clock, at which time the output Q is set to the same value as D. Otherwise, the value of output Q is held constant.

To enhance its functionality, normally an asynchronous “Set” (Q is set high) and an asynchronous “Reset” (Q is set low) is added to the D Flip-Flop as shown in Figure 8 (active low Set― and Reset―).

Answer the following questions:

  1. Why are Set― and Reset― referred to as asynchronous set and reset?

  2. Why do Set― and Reset― go to both the master and the slave latches?

  3. How could you save one inverter?
