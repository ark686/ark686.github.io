5. Background ​

Digital signals are considered either to be "zero (or "false"), represented by a low voltage (typically zero volts) or "one" (or "true"), represented by a high voltage (typically 3.3 or 5 volts).

There are three basic logic elements which can be used to create any arbitrary combinational logic function:

  • NOT (also called an inverter)

  • AND

  • OR

5.4 NAND Gate ​

Often it is useful to be able to use "negative" logic, and so rather than using AND gates, NAND gates are usually used. A NAND gate can be thought of as an AND gate followed by an inverter. A NAND gate can be converted to an AND gate by adding an additional inverter. It also turns out that a NAND gate can be implemented using fewer transistors than an AND gate.   1. Construct the circuit shown in the Circuit JS simulator (https://www.falstad.com/circuit/circuitjs.html). The “NAND” and “Inverter” can be found under “Draw > Login Gates, Input and Output”.

  2. Add inputs:

    1. To systematically apply all possible input combinations, one approach is to consider the inputs as bits of a multi-bit binary number, have that number start at zero and then increment that number by one for each row of a truth table, until its maximum value (all bits being ones). For an n-bit binary number, there are 2n possible values. With n=2, there are 22=4 input combinations.

    2. In hardware, this can be achieved by having each input driven by a digital clock (“Clock” can be found under “Draw > Inputs and Sources”), with the frequency of each bit twice the frequency of the previous bit:
